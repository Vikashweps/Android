#  Android MultiTool

Учебное приложение на **Kotlin**, объединяющее калькулятор, аудиоплеер и геолокацию. Демонстрирует работу с системными сервисами Android, разрешениями и UI.

##  Функции
- **Калькулятор**: Базовые арифметические операции.
- **Плеер**: Воспроизведение аудио из памяти устройства (Play/Pause/Next).
- **📍 Геолокация**: Определение текущих координат (GPS/Network).

##  Стек
- **Language**: Kotlin
- **UI**: XML Layouts
- **APIs**: `MediaPlayer`, `FusedLocationProviderClient`
- **Build**: Gradle (Kotlin DSL)
- **Min SDK**: 24 (Android 7.0)
